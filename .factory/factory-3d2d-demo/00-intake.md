## 我的理解（一段話）

做一個「技術可行性展示」：一條通用組裝產線的寫實 3D 場景（three.js + R3F），可切換 2D 平面圖，最終輸出 15 秒 MP4 給團隊理解。全部動畫是時間 t 的純函數，讓互動預覽與逐格錄影共用同一份邏輯。本輪只做階段 1–3（骨架、領域資料與資產管線、3D 寫實場景），完成後給使用者看截圖再繼續。

## 範圍
- 要做（本輪）：
  - Vite + React 19 + TS 專案骨架、vitest、playwright
  - 領域模型（ISA-95：Site/Area/Line/Cell/Equipment）+ 配置驗證 + 動作純函數（輸送帶料件、機械手臂取放）
  - 資產管線：清冊 → 下載 → 最佳化 → 驗證，每支是一個可串接的小工具，用 GNU parallel 並行
  - 3D 場景：廠房、HDRI、PBR、陰影、後處理、設備動畫；截圖
- **不做**（本輪明確排除）：
  - SVG 2D 平面圖與 3D/2D 切換（階段 4）
  - 鏡頭腳本與 MP4 輸出（階段 5）
  - 連接真實產線資料（OPC UA／MQTT）、登入／權限、多租戶、部署上線、Remotion
